# Variables de entorno

| Variable | Descripción | Valores |
|---|---|---|
| `PORT` | Puerto HTTP | `8080` |
| `LOG_LEVEL` | Nivel de logs | `info`, `debug`, `error` |
| `DATABASE_HOST` | Host PostgreSQL | `localhost` |
| `DATABASE_PORT` | Puerto PostgreSQL | `5432` |
| `DATABASE_NAME` | Base de datos | `clientes` |
| `DATABASE_USER` | Usuario | `postgres` |
| `DATABASE_PASSWORD` | Contraseña | *(secret)* |
